# 🐚 Bash Learning Scripts

This repository contains Bash scripts created while following a comprehensive Bash tutorial.

## 📺 Source of Learning

* **Title:** Full Length Guide to Learning the Bash Shell
* **Instructor:** Dave Eddy (You Suck at Programming)
* **YouTube:** [https://www.youtube.com/watch?v=Sx9zG7wa4FA](https://www.youtube.com/watch?v=Sx9zG7wa4FA)

This tutorial covers Bash from beginner to advanced concepts, including:

* File manipulation
* Variables
* Functions
* Conditionals
* Scripting fundamentals

## 📂 Purpose of This Repository

This folder is used to:

* Practice Bash scripting concepts
* Store example scripts created during learning
* Experiment with command-line automation

## 🚀 How to Run Scripts

Make a script executable:

```bash
chmod +x script.sh
```

Run the script:

```bash
./script.sh
```

Or:

```bash
bash script.sh
```
